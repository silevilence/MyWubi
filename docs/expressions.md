# Emoji 与颜文字

EM 功能正在开发。共享词库格式、全局配置、资源快照、候选追加和双端词库管理已接通，安装包随附完整词库与许可；专用模式及显示验收尚未完成，不能据此宣称双端完整交付。

## 选择与导入词库

Windows 常规设置与 Android 设置中的表情词库区域，分别提供两类词库的用途开关、词库选择、版本、条目数及完整来源声明。选择“导入词库”会先验证类型、格式与许可字段，再复制到配置目录下独立的 `expressions/imports/` 子目录；原文件可移走，Android 不需要长期保留文件选择器授权。导入不直接激活，仍需保存设置。“使用内置词库”恢复默认选择，保留已导入文件。

Windows 使用现有便携/AppData 配置路径，Android 使用应用私有目录；新建配置及已有配置缺少内置资源时会从随包资源准备。升级不覆盖已有资源和选择。内置文件已被修改或损坏时不会自动覆盖，设置中会显示校验错误。词库列表的“校验通过”表示文件可解析，不代表所有已打开宿主已采用；保存和热重载失败时保留旧的有效配置与资源。

## 全局配置

```toml
[expressions.emoji]
append = false
search = false
# resource = "expressions/custom-emoji.mwe"

[expressions.kaomoji]
append = false
search = false
# resource = "expressions/custom-kaomoji.mwe"
```

`append` 控制普通输入候选后的追加，`search` 控制专用模式可用性。两者均缺省关闭，任一个开启才加载该类资源。省略 `resource` 分别指向 `expressions/emoji.mwe`、`expressions/kaomoji.mwe`。路径相对于共享 `config.toml` 所在目录，也允许绝对路径。主码表切换不修改这些配置；不向主码表 YAML 头写入任何表情设置。

## 独立词库契约（版本 1）

UTF-8 文件第一行为 `# MyWubi Expressions 1`，之后是一个 JSON 对象。建议扩展名 `.mwe`；识别依据是内容，改名为 `.dict` 也不能作为主码表或临时拼音/英文表。普通码表不能作为附加词库。

文档包含 `kind`（`emoji` 或 `kaomoji`）、`name`、`version`、`sources`、`entries`。每个来源必须提供 `id`、`url`、固定 `revision`、`license` 和版权许可 `notice`。每条词条包含：

- `text`：实际输出，逐码点保留空格、反斜杠、ZWJ、变体选择符及组合字符。
- `name`：显示名称；`triggers`：完整触发词数组，用于严格匹配实际文字候选。
- `tags`、`aliases`：查询标签、名称别名及兼容序列，缺省为空。
- `order`：稳定顺序，同分保持原文件顺序；`sources`：非空来源标识数组。

同一输出不能重复收录；多个触发词归并到同一条目，不合并不同肤色/性别等输出序列。文件最多 64 MiB、100000 条。单条输出及每个触发词/标签/别名最多 512 个 Unicode 标量值，拒绝空白输出、控制字符、多行和 Unicode 行/段分隔符；不通过截断或替换字符修复数据。导入生成器必须记录排除原因。资源格式严格校验未知字段和来源引用。

只读索引在快照构建时建立，逐键查询不读文件。完整触发词精确查找，例如“开心”命中，“不开心”不会按子串命中。更宽松的查找只用于后续专用模式。

## 普通候选追加与分页

主模式及临时拼音按实际文字候选的完整文本查询 `triggers`。匹配顺序是原文字候选顺序、该触发词的 Emoji、该触发词的颜文字，各词库内部保持 `order` 顺序；整个查询按完整输出去重，已有文字候选优先。输出表情不再参与递归匹配。英文、密码/私密范围和上屏后预测候选不追加表情。

原文字页的文字先出现，表情填入该页剩余位置；装不下的表情接着显示在连续的表情页中，之后开始下一组文字候选。不会为了填满一个表情续页而把下一文字页的首选放到页中间。启用追加且有命中时，每个实际页面最多为配置页大小与 9 的较小值，以保证数字 1～9 可选；配置为 10 时，原文字组的第十项也会进入续页。关闭追加或没有命中时保留原分页行为。

例如页大小 3，第一文字页有 3 个词、关联 4 个表情，后面还有 1 个文字候选时，实际页面依次为：3 个文字 → 3 个表情 → 1 个表情 → 最后 1 个文字。表情没有永久展示截断，所有续页均可浏览。手机展开查询使用相同完整顺序，一次窗口最多返回 256 项，可继续查询后续窗口。

桌面页和手机窗口复用同一份只读候选序列及 ID，翻页不重新展开词库。混合候选翻页、修改编码、退出模式、切换资源或宿主范围变化会使旧查询版本失效。表情名称单独作为提示传递，选中时只提交原始输出字符串。唯一文字候选在满码时若有可追加表情，会保留候选供选择；没有表情时保持原自动上屏规则。确定未写入时，触屏会话及 Windows 临时会话允许重试；Windows 主模式保持原清理恢复协议。

## 失败行为

启动时某类附加资源缺失、损坏或类型不符，只隔离该类资源，保留具体路径与错误，其余词库和主输入继续工作。两个用途均关闭时不访问对应文件。

热重载失败不发布新快照，保留旧的有效配置与词库；失败依赖路径仍交给现有监视机制，修复后可重试。资源错误由共享核心产生，两端使用相同校验逻辑。配置保存拒绝把已存在的表情资源指定为主码表；手改配置绕过保存时，运行时加载再次拒绝。

保存前也校验已启用的附加资源；失败不覆盖现有配置。关闭两种用途后，允许保存尚未安装或暂时不可用的资源路径。

验收记录见 `docs/validation/expressions.md`。显示和真实宿主验证未完成前，不宣称全部字形已支持。
