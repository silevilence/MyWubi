# Android 应用更新验收

任务来源：ROADMAP.md AU-01～AU-04。日期：2026-11-03。

## AU-01

- 发布流程从签名 APK 的 aapt badging 提取包名、版本号、最低 SDK 和 ABI，生成
  `android-update.json`，与 APK 一起先上传草稿，再公开 Release。
- 检查仅请求固定 GitHub Release API 与该正式 Release 下的元数据；网络任务运行在
  IO 协程，不接收输入文本、编辑器或引擎句柄。仅打开键盘时触发，不在逐键路径调用。
- 成功检查间隔 24 小时，失败从 15 分钟指数退避至 24 小时；手动检查可绕过时间限制，
  但不能创建并行检查。失败保留已知版本，设置页明确显示失败；成功无更新清除缓存。
- API 34 x86_64 模拟器 `AppUpdateTest` 4 项通过：新/同/旧版本、SDK/ABI、草稿/预发布、
  非公开/缺失/异常元数据、退避、慢请求不阻塞主线程、并发去重、失败重试和缓存重建。
- Python 发布脚本测试 4 项通过。APK 构建通过。真实 GitHub 发布未执行；下一次签名
  发布才会提供此元数据，旧版本无元数据时主动检查报告失败，不报告“最新”。

## 设备范围

当前仅连接 API 34 x86_64 模拟器；没有可用 ARM64 真机。未测设备与系统行为不以构建
成功代替。后续各阶段结果记录在此文件。

## AU-02

- `KeyboardIdleTest` 2 项主机测试通过：1.8 秒稳定间隔，连续直输、触摸长按、
  预编辑、候选交互、空临时会话均阻止提示。
- API 34 `UpdateToolbarTest` 通过：静态提示点、触摸时隐藏但设置按钮仍能点击、
  英文/数字/密码呈现、候选优先、更新清除。真实 `ExternalHostTest` 2 项通过，
  覆盖 g/g/l/l → 王、选词、大小写、长按退格及隐藏后取消重复。
- 修正旧测试在上屏后仍寻找“收起”的断言，改为验证候选区域随提交消失。
- 服务在新输入框、显示/隐藏和重建时重置静置间隔，销毁时移除计时器和订阅。
  检查结果只改变缓存/可用版本，不改变输入状态；候选列表存在时不给设置提示占位。
