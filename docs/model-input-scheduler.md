# MI-08 调度器进展

`model_input::scheduler` 将评分放到独立工作线程，最多一项正在计算、一项可替换等待。
相同版本合并，连续输入替换旧等待项；交付时再检查完整 RequestKey、截止时间与身份。
取消不等于计算已停止：合作后端检查取消，无法合作的 native 调用仍可能继续到返回。
Drop 不阻塞输入线程；立即释放非合作计算仍需 MI-12 的独立进程生命周期。

失效会丢弃等待/结果、取消活动计算，并唤醒空闲工作线程清除模型缓存。
测试覆盖 100 次连续请求只执行首项和末项、重复合并、结果过期、切换失效，
以及没有后续输入时也清除空闲缓存。统计仅保存数量，不记录输入原文。

预测路径现已通过 `worker`、Windows 独立服务/IPC 和 Android 控制器接入，
包含冷加载隔离、暂停/空闲卸载和平台资源退让，详见[模型接入](model-input-integration.md)。
排序产品路径暂缓，MI-08 保持部分完成；线程测试不替代代表性输入时延或设备资源验证。
