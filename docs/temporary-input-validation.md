存活分配请求字节：拼音码表及索引 19,183,388 字节（约 18.30 MiB）；独立反查索引 19,242,458 字节（约 18.35 MiB）。不含源文件文本、分配器额外开销、UI 或进程其他对象；不是系统工作集。反查索引用同规模的合成数据单独计量，实际大小取决于主码表。

整体审核移除了拼音码表不再使用的通用 Trie，比修改前同数据节省 6,280,786 字节。共享开发主机有负载波动，短前缀两轮约 1.2～1.6 ms；不据此宣称延迟改善。逐键检索复用已加载的只读索引，没有文件读取、重复加载或逐键全表反查；宽前缀仍需处理匹配范围中的所有词条。

## 整体审核修复

- 临时输入取消遇到宿主拒绝编辑时，保存“删除原文”的清理意图，重试仍删除 composition，避免把取消内容保留为上屏文字；新增回归用例。
- 临时模式的固定空格提交优先级只作用于临时模式，保留主模式自定义空格翻页绑定；新增对照用例。
- 纯汉字多字词条校验字数与显式音节数，避免未分隔词组被当作单音节接受；混合文本不猜测字音关系。
- 提取快照发布路径供测试直接验证失败保留和修复重试，并增加原生文件监听验收。
- 增加可直接载入的三个示例文件及组合行为测试；补充使用说明、基准和本记录。
