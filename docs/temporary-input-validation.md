## 配置界面缺字修复

实机复现了按钮省略号和状态符号显示为问号 / 方框的问题。`eframe` 关闭默认特性后没有启用 `default_fonts`，而内嵌中文字体未覆盖这些字形；另有警告符号中的 U+FE0F 变体选择符及状态圆点缺字。

- 开启 `default_fonts`，保留中文字体优先级并补上后备字体。
- 警告文字使用普通 `⚠`，去除不受支持的变体选择符；状态圆点改为直接绘制。
- 新增字形覆盖测试，修复前能复现缺字，修复后通过。
- 在虚拟机更新最终 settings.exe，复查浏览 / 管理按钮省略号、权限警告和安装状态圆点，均正常显示。
