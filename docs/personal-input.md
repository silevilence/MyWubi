# 个人用预测模型

所有操作在本地完成，三个许可分别控制收集、后台学习和使用个人预测，默认均关闭。
不收集密码、私密输入或宿主禁止个性化学习的字段。已有正文、粘贴和来源不明的变化不自动成为个人偏好。

## 事件格式 v1（MI-40）

`core_engine::personal::Event` 保存来源、会话、单调序号、时间及模式。来源 ID 每次创建记录器时由系统随机数产生，
事件 ID 为来源 ID 加序号。导入保留原 ID；新安装、克隆、服务重建均产生新来源。
时间只作保留期限和跨来源的近似排序，同一来源的因果关系始终按序号判断。

每条事件包含变更前的有界上下文，可选变更后上下文。左右文和选区的 null 表示未知，空串表示已观察为空；
坐标注明 UTF-16 或 Unicode scalar，以及绝对/窗口相对范围。截断与断裂独立标记，不将每次提交拼接成完整文档。
预编辑、候选展示、提交、宿主编辑、会话边界和丢失区间采用同一事件流。提交区分已确认、命令接受、拒绝和未知。
编辑的实际来源无法确定时为 Unknown；只有可证明关联的删除/纠正才引用原提交。
展示事件记录实际顺序、候选身份和来源、请求、模型与策略；提交通过请求及候选身份关联展示。
新增 JSON 字段以扩展字段保留；未知格式版本拒绝导入，不以静默丢字段兼容。

样例语义：普通上屏与预测选择均是 Commit；句中输入保留右文；选区替换保留选区；
失败提交为 Rejected/Unknown；上下文读取失败保留 null。只有确认且上下文连续的记录可成为训练样本。

真实个人效果、ARM64 真机热量/电量均需要独立验收；合成回放只证明实现行为。

## 本地数据包（MI-45）

设置中的导出只读取持有进程锁的一致快照，不暂停基础输入。`.mwp` 是单个有界容器，不是 ZIP，
没有可解包路径、脚本或可执行内容。最大负载 128 MiB。清单包含格式版本、数量、来源、事件摘要，
以及由于保留期限或容量淘汰而缺失的编辑引用；原事件和身份不因导出而改写。

明文包含输入正文和上下文。加密包使用随机 16 字节盐、随机 12 字节 nonce、
PBKDF2-HMAC-SHA256（600,000 次）及 AES-256-GCM；头部为认证附加数据。密码不可恢复。
包头、认证、版本、数量、事件身份、引用及大小校验均在写入前完成。数据和密码不写日志，不上传服务器。

2026-11-12 集中验证：本机生成的 100 事件明文/加密包由 Android x86_64 JNI 导入、训练并重新导出，
本机再导入均为 0 新增、100 重复、0 冲突；Android 新生成的 42 条事件可在本机导入。
坏密码、损坏、截断、未来版本和淘汰引用见 `personal_input/tests/personal_flow.rs`。
