# 个人用预测模型

所有操作在本地完成，三个许可分别控制收集、后台学习和使用个人预测，默认均关闭。
不收集密码、私密输入或宿主禁止个性化学习的字段。已有正文、粘贴和来源不明的变化不自动成为个人偏好。

## 事件格式 v1（MI-40）

`core_engine::personal::Event` 保存来源、会话、单调序号、时间及模式。来源 ID 每次创建记录器时由系统随机数产生，
事件 ID 为来源 ID 加序号。导入保留原 ID；新安装、克隆、服务重建均产生新来源。
时间只作保留期限和跨来源的近似排序，同一来源的因果关系始终按序号判断。

每条事件包含变更前的有界上下文，可选变更后上下文。左右文和选区的 null 表示未知，空串表示已观察为空；
坐标注明 UTF-16 或 Unicode scalar，以及绝对/窗口相对范围。截断与断裂独立标记，不将每次提交拼接成完整文档。
预编辑、候选展示、提交、宿主编辑、会话边界和丢失区间采用同一事件流。提交区分已确认、命令接受、拒绝和未知。
编辑的实际来源无法确定时为 Unknown；只有可证明关联的删除/纠正才引用原提交。
展示事件记录实际顺序、候选身份和来源、请求、模型与策略；提交通过请求及候选身份关联展示。
新增 JSON 字段以扩展字段保留；未知格式版本拒绝导入，不以静默丢字段兼容。

样例语义：普通上屏与预测选择均是 Commit；句中输入保留右文；选区替换保留选区；
失败提交为 Rejected/Unknown；上下文读取失败保留 null。只有确认且上下文连续的记录可成为训练样本。

真实个人效果、ARM64 真机热量/电量均需要独立验收；合成回放只证明实现行为。

## 本地数据包（MI-45）

设置中的导出只读取持有进程锁的一致快照，不暂停基础输入。`.mwp` 是单个有界容器，不是 ZIP，
没有可解包路径、脚本或可执行内容。最大负载 128 MiB。清单包含格式版本、数量、来源、事件摘要，
以及由于保留期限或容量淘汰而缺失的编辑引用；原事件和身份不因导出而改写。

明文包含输入正文和上下文。加密包使用随机 16 字节盐、随机 12 字节 nonce、
PBKDF2-HMAC-SHA256（600,000 次）及 AES-256-GCM；头部为认证附加数据。密码不可恢复。
包头、认证、版本、数量、事件身份、引用及大小校验均在写入前完成。数据和密码不写日志，不上传服务器。

2026-11-12 集中验证：本机生成的 100 事件明文/加密包由 Android x86_64 JNI 导入、训练并重新导出，
本机再导入均为 0 新增、100 重复、0 冲突；Android 新生成的 42 条事件可在本机导入。
坏密码、损坏、截断、未来版本和淘汰引用见 `personal_input/tests/personal_flow.rs`。

## 合并、覆盖与清除（MI-46）

导入先预览新增、重复、同身份冲突和覆盖范围。确认时再次核对数据快照摘要；预览后发生的新输入会使
确认失败并要求重新预览，避免静默丢失并发输入。同身份不同内容始终拒绝；同文本不同事件仍保留频次。
合并按原事件 ID 幂等处理；覆盖仅替换 `personal/` 的事件集合，不改应用配置、用户词库或通用模型。
整体写入使用新日志代次与原子快照切换，失败不发布半套数据。

淘汰记录保留不含原文的 ID/摘要，最多 `min(100000, max_mb * 1024)` 条；超出此界限的旧身份可能被遗忘。
清除记录也清除这些去重身份和训练缓存，因此之后明确导入旧包会恢复那些原始记录。
保留模型时，其训练事件身份及数据摘要仍避免把同一批记录反复累加为新频次。学习采用有界重训，而非累计重复计数。

覆盖会改变数据 epoch，旧模型立即失效，需在本端重新训练。合并新增数据保留可用模型至下一次通过验证的发布。
只清除记录与训练缓存不代表清除模型知识；勾选“同时删除个人模型”才会清除活动及上一版本模型。
普通退出刷写仍获许可的排队事件；关闭许可或进入敏感字段会撤销待写队列。清除前必须先关闭并保存收集开关。

模型文件为本地派生产物，不随原始数据包合并。跨端以原始事件交换后分别训练，不能直接平均两个模型参数。

## 实验训练、预测与调度

实现位于独立的 `personal_input` crate，核心事件定义留在无平台 API 的 `core_engine`。
Windows TSF DLL 只采集和异步预测；`settings.exe --personal-worker CONFIG` 执行学习，同一配置目录使用进程锁。
Android 在原生单线程 worker 学习，输入主线程只提交/轮询有界请求。三项开关不隐式相互开启。

第一版是可替换的短语统计实验：比较精确 8 字后缀与 1/2/4/8 字回退，右文前 8 字参与匹配；
输出仍遵守核心候选合法性限制（中文短语、长度上限及右文去重）。数据不足、上下文不可读或模型失效时不显示个人候选。
只有已确认、上下文完整且适合当前预测器的输入进入训练；普通选择权重 2，模型建议被用户选择后权重 1。
仅展示未选择的候选不训练。可证明关联的纠正会撤回样本；不能识别的宿主变化保留 Unknown，不猜测编辑来源。

至少 20 条有效样本、有界重训最多最近 20,000 条、单线程、计算阶段 2 秒软预算、模型最大 8 MiB。
后台等待 30 秒输入空闲及 5 分钟间隔；手动更新跳过间隔但保留空闲和资源门控。
Windows 检查电源与低内存；Android 要求输入法可见、充电且非低内存/省电/严重温控状态，并每秒重检。
Windows 不在 DLL 中启动训练线程。学习开关停止下一批，输入活动/资源变化取消当前批；关进程仍可从原始事件重建。
设置可查看样本数、模型字节数、最近版本/更新时间、批次耗时和等待原因。文件读取与原子发布成本不构成严格实时承诺。

每次模型绑定数据 epoch、原始事件摘要、训练事件身份、算法和 tokenizer 版本。重复数据不累加频次。
新版本先做时间顺序 80/20 验证，并用旧模型未训练的至少 4 条新增验证样本比较前三命中和错误建议；
结构、容量、取消或防退化失败保留旧模型，成功时原子发布并保留上一版供回退。
发布前的检查用于拦截退化。独立的离线评测使用更晚的一段输入，模型、词表和中间样本只存在评测进程内存中。

### 用自己的导出包评测

```powershell
cargo run --offline --locked --release -p personal_input --bin personal_check -- evaluate "个人导出包路径" tables/wubi86.dict
```

程序校验数据包后按时间重放，输出汇总 JSON。加密包的密码由本次进程的 `MYWUBI_EVAL_PASSWORD` 提供。评测不启动采集、不写入当前模型。数据包须有至少五次确认提交，且验证段和最后测试段都有可用样本。

每组结果还会区分相同左右文下重复上次目标、改用另一目标、从未出现这种左右文三种情况。比较时只查对应训练期的历史。报告单列能追溯到已选个人预测的纠正次数，按原提交去重。神经网络比较使用最近最多 20,000 条有效样本，训练超过 2 秒预算时将该项结果留空。

- 以确认提交数的 40%、60%、80% 为三个时间切点。同一数据源始终保持事件顺序。每个版本只使用切点以前已经发生的提交和纠正。
- 以前 60% 训练的精确后缀、逐级回退模型，在接下来的 20% 上选型。前三命中增加且错误展示不增时选回退，否则选精确后缀。达不到 20 条可用于训练的输入时，个人模型保持等待。
- 将最后 20% 留给共同测试。对照系统码表预测、三个时期的个人模型、个人候选优先再补词典的实验组合，以及一个小型神经网络。神经网络只用于离线对照，固定 256 个位置字符特征桶、16 个隐藏单元、最多 128 个历史词、4 轮训练、种子 7。各方法最多显示三项。
- 报告样本数、首选和前三命中、展示次数、展示但前三均未命中次数，以及句末／句中／替换、码表外、未在历史出现的分组。只有后续实际选词与对照输入都可观察时才能计算实际省键。普通记录缺少这一对照时，`observed_net_keys_saved` 为 `null`。旧模型中的 `saved_keys`、`new_phrases` 是字符数和多字命中的历史代理值。
- 热预测延迟统计到产生候选列表为止，神经网络的参数字节数仅含数值权重。质量结论和宿主端耗时见[集中验收记录](personal-input-acceptance.md)。

### Windows 便携目录

Windows 用户配置目录内沿用配置旁的 `personal`。位于其他位置的便携配置按配置路径分开，将记录、缓存和模型写入当前账户的 `%LOCALAPPDATA%\MyWubi\portable`。同一便携安装的不同 Windows 账户各自学习。用 `personal_check store-path CONFIG` 可查询实际路径。Android 仍使用应用私有目录。

旧版便携目录已有记录时，在设置中刷新个人模型状态，确认所有权后选择“导出我的旧版便携记录”，再通过现有预览、合并、训练流程恢复。旧目录中的原始记录由原持有人管理。复制便携程序到另一目录或设备时，通过导出包转移个人数据。
