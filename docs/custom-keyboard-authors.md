# 自定义键盘包作者说明

可直接导入 `docs/templates/mywubi-keyboards-4.mywubi-skin`；Windows 皮肤编辑器和 Android 自定义键盘页也能添加相同模板。包包含原 Windows/Android 外观与四种布局，不会因导入而自动启用。

| 组件 | 模式 | 点击 | 精确输入 |
| --- | --- | --- | --- |
| full26 | 形码、拼音、英文 | 一个确定字母 | Q 键长按为隔音符；Shift 切换大小写 |
| shape14 | 形码 | 标注的一个字母组 | 上方三向为首字母，下方三向为次字母 |
| shape9 | 形码 | 一个三字母组或二字母组 | 上方三向、下方三向、左方向分别对应组内字母 |
| pinyin9 | 拼音 | 隔音符或 ABC/DEF 等字母组 | 前两字母用上下合并，第三/四字母用左右方向 |

“九键”表示输入按键分组，与 PNG 的九宫格切片（保留边框伸缩）不是同一概念。模板采用矩形逻辑坐标，支持留白、错位、宽高不同、分区和独立横屏画布；不支持任意多边形。

## 组件与依赖

布局放入 `android/layouts/*.toml`，映射放入 `android/mappings/*.toml`。平台 metadata 中分别声明 `kind=layout`、`kind=mapping`；布局对映射组件声明精确版本依赖。布局至少需要 `keyboard.layout/1`，组动作需要 `input.groups/1`，方向绑定需要 `keyboard.directions8/1`，合并方向需要 `keyboard.direction-groups/1`。引用必须在本包内；跨包选择只能由运行端的组合选择器绑定。

`charset` 是完整目标字符集，`modes` 是允许的模式，不能只改标签而隐式改变动作。`action={kind="Group",value="g0"}` 一次仅发送一个输入位置，不能改为连续发送组内字母。未消歧组不会自动选择某个字母。输入模式、映射版本、摘要和 revision 一起绑定；英文、数字、电话的自定义组合禁止 Group 动作，密码始终使用内置确定字符布局。

Android 壳层固定提供空格、回车、取消和恢复入口，布局必须包含退格。退格使用专用重复删除状态机；若设置布局默认方向，应为退格显式禁用全部方向。样式使用已知语义角色或 `optional_styles` 中声明的回退；固定键位图片不能直接套用其他几何布局。

## 手势、编辑与验证

八方向按上、右上、右、右下、下、左下、左、左上排列；使用 `up_left+up+up_right` 把多个方向合并为同一动作。布局默认值可被按键覆盖或显式禁用，同层重叠、禁用与覆盖冲突会拒绝。24 dp 起滑，12 dp 回中心取消，5° 防抖，超过 160 dp 取消；仅松手确认一次。长按先完成会锁定长按动作，滑动先开始则取消长按。模拟轨迹见共享 `core_engine/tests/fixtures/protocol/gestures.json`。

Windows 编辑器先保留组件草稿，再校验并写入，之后导出新包。只改指定布局/映射；Windows 参数、共享资源和未知合法扩展保留。不支持的新能力组件保持不可用，不破坏独立外观。改变布局或映射后应提升包版本；不要覆盖同 ID、同版本但内容不同的安装包。

Android 流程：导入库 → 选择模式/布局/映射 → 预览 → 应用。外观未保存时先保存设置；换肤保持布局选择。正在输入或触摸时延后切换，恢复默认入口独立于自定义按键。包损坏或资源缺失时保留旧完整组合；冷启动无法恢复时回退内置。

## 往返与验收

核心测试覆盖解析、编辑、导出、再导入后资源字节一致、旧纯外观包、未知能力、损坏映射、固定素材不兼容、模式选择与恢复。Android `KeyboardPackageTest` 复用这些模板验证 JNI 解码、保存/恢复与导出再导入摘要；系统分享面板由现有皮肤库导出入口复用。设备交互与分享面板的最终证据另记，不能由桌面示意图替代。

重新生成模板：`cargo run -p core_engine --offline --example keyboard_templates -- <新文件路径>`。使用现有本地码表和组件，无需联网下载。
