# 本地模型辅助输入验证记录

## MI-01：评测基线（部分完成）

2026-11-04：`model_input` 是独立离线评测 crate，不被 TSF DLL 链接。
使用当前核心的 `Dictionary::search`，保留精确匹配优先及拼音边界规则。
`model_input/evaluation/samples.json` 有 38 个自编病例，训练 8、开发 10、保留测试 20。
样本文本与用户词库 fixture 按项目 MIT 许可发布，不含用户实际输入。
拼音候选来自现有 `tables/pinyin.dict`，来源、固定版本、哈希及许可见
`tables/sources.json` 和 `tables/licenses/rime-pinyin-simp-LICENSE.txt`；形码使用
项目 MIT 示例码表。未读取未跟踪的私有码表。

每个病例只有光标前已经存在的 prefix、当前编码、合法候选快照和独立目标标签。
例如“下周去 xian”仅提供“下周去”，没有未来的“出差”。编辑前文病例提供编辑后的
前文，不沿用旧文本。无上下文以空字符串表达。输入结构拒绝未知字段。
训练、开发、测试按来源组隔离；校验器拒绝同组或完全相同完整文本跨分割。
小样本仍存在相似语义模板，因此这只是工程回归集，不能用来宣称泛化效果，
产品选型前须另行收集有许可、按真实来源文档隔离且足够大的独立保留集。

复现（仓库根目录）：

```powershell
cargo test -p model_input --locked
cargo run --release -p model_input --bin evaluate --locked
```

普通运行核对合法候选快照；码表变化即失败。只有有意更新数据集时才运行
`cargo run -p model_input --bin evaluate -- --freeze-candidates`，审核差异后重新冻结。
字词统计仅从 train 联想样本学习最近一至两个字符到下一字词的计数，稳定排序、最多 64 项。
排序与联想分别输出 all 和各子集原始计数，分母不可隐藏：Top-1/3 除以 samples；
排序条件命中率另除以 recalled；召回率 recalled/samples；改错率
correct_to_wrong/baseline_correct（分母为零应显示不适用）；净收益为
(wrong_to_correct-correct_to_wrong)/samples。基线与自己比较改错为零，不代表模型安全。
操作数按每页 5 项，命中后一次显式选词和 floor(index/5) 次翻页；未召回病例不虚构
可完成的操作数，自动上屏和真实用户选词成本留给端到端轨迹评测。

冻结结果见 `model_input/evaluation/baseline.json`。测试排序 12 例：召回 11，首选 5，
Top-3 8；歧义子集 3 例首选 1。测试联想 8 例：召回 6，首选 6。
训练样本未用于报告；结果完全确定，不包含伪造时延。

## 设备方案与预先固定的实验预算

本机：Intel Core Ultra 7 165U，12 核/14 逻辑处理器，33,905,598,464 字节内存，
Windows x86_64；Rust/Cargo 1.99.1。CPU 测试禁用 GPU/NPU，最多 2 推理线程。
该机器是开发参考机，不能代表所有普通电脑。Android ARM64 真机尚未连接，
ADB 列表为空；现有 x86_64 模拟器不能代替 ARM64 或 16 KB 页真机验收。
MI-01 最后一项和整体完成状态因此保持未勾选。

在跑模型之前固定下列实验门槛，后续只能带理由版本化调整，不能看结果后静默修改：

| 项目 | Windows 开发参考 | Android ARM64（待登记设备） |
| --- | --- | --- |
| 前文 Unicode 字符 | 0 / 32 / 128 / 256 | 同左 |
| 当前合法候选数 | 1 / 5 / 16 / 32 / 64 | 同左 |
| 输入/上屏主线程 P95/P99 | ≤ 8/16 ms，开启较关闭 P95 增幅 ≤ 2 ms | 同左 |
| 排序等待截止 / P95 | 100 ms / ≤ 100 ms | 120 ms / ≤ 120 ms |
| 联想等待截止 / P95 | 250 ms / ≤ 250 ms | 300 ms / ≤ 300 ms |
| 有效到达比例 | ≥ 95% | ≥ 95% |
| 增强进程内存增量 | ≤ 768 MiB | PSS ≤ 384 MiB |
| 连续输入 | 30 分钟，固定 5 字母/秒、每 5 秒提交 | 同左，记录温度/电量/降频 |
| 质量 | 独立保留集首选净收益 > 0；原正确改错 ≤ 1% | 同左 |

每组合预热 20 次、测量至少 1000 次；分别记录冷加载、首次前文计算、缓存命中、
外部编辑导致的缓存失效；端到端从按键/提交到实际可用候选，报告 P50/P95/P99，
不以平均 tokens/s 替代。内存记录基线、峰值与每分钟样本，停止后 60 秒确认释放。
固定首位模式独立报告第二位以后排序，不声称提高首选。持续测试记录电源模式、
系统/运行库/模型版本和哈希、量化、线程数、宿主应用、温度/竞争负载与无法取得的指标。
手机具体 SoC、RAM、系统版本、页大小、温度测量能力尚未确定，设备门槛未验收。
