### 存储与跨端验证

- Windows 便携配置改为按用户分开保存个人库。两名沙盒用户共用同一个配置时得到不同目录，第二名用户实际打开第一名用户的模型文件被拒。旧版便携数据可由用户从设置中主动导出、预览并合并。
- 在沙盒的独立 64 MiB 测试磁盘上，将剩余空间压到 8 KiB，写入按预期返回磁盘已满。释放空间后，原有 100 条记录全部识别为重复，再导入的 42 条均成功。另行执行了默认跳过的 128 MiB 上限淘汰与恢复测试。
- Android API 34 模拟器上的 10 项仪器测试通过。独立应用里的真实编辑框验证了候选连续上屏、删除、旋转后继续输入、训练更新、模型回退及停止收集后继续预测。短读和读取失败用可控的 `InputConnection` 单独覆盖。ARM64 与 x86_64 原生库均已离线构建。
- 本次 Windows 的 100 条合成记录在 Android 通过明文包及加密包导入并重新导出。两份回传包在 Windows 均得到 0 新增、100 重复、0 冲突。用户授权的个人包只用于本机离线评测。

### Windows 实际输入与后台学习

修复了 Windows 只在激活时订阅旧编辑器通知的问题。Edge 中选择个人候选后按撤销，正文和选区都恢复了，存储里也找到了指向这次已确认个人提交的编辑记录。宿主能证明文本被移除，记录保留为 `Delete`。选区替换保留了光标右侧原文。对同一合成短语手打需要编码键和空格两键，选择已展示的候选用一键。

在同一 Edge 编辑框中交替打字、空闲和后台学习，共运行 1,838.1 秒。144 轮均选中预期的合成候选，宿主正文逐轮核对通过。采样期间观察到 7 个不同的生效版本，模型样本数由 104 增到 229，库文件总量由 135,295 增到 1,185,649 字节。

| 沙盒端到端测量 | P50 | P95 | P99 |
| --- | ---: | ---: | ---: |
| 按下提交键至观察到基础正文 | 12.30 ms | 17.37 ms | 38.38 ms |
| 基础正文已出现至发现候选、按键选中并观察到最终正文 | 78.33 ms | 114.54 ms | 136.14 ms |

这些时间包含自动化读取正文和候选的开销。采到的后台学习进程工作集最高为 13.24 MiB，Edge 主进程最高为 190.09 MiB，主进程 CPU 时间在首尾采样间增加 36.73 秒。工作集是间隔采样值，不能代表整机功耗。

关闭收集后回退上一版本，Edge 仍能选词上屏，事件文件大小保持不变。另一次测试将存储锁住 1.5 秒，超过配置的 1 秒预测等待时间，基础形码仍能上屏。释放锁后旧候选没有出现，下一次形码提交和光标位置均正确。

在 Edge 中又手动输入了 8 次原模型没有给出的后续短语。后台更新后，可在同一个编辑框里连续选中两个预测词，光标最终落在第 9 个 UTF-16 单位后。回退后，第一个候选仍可上屏，刚学的第二个候选消失。经典记事本也通过了普通提交和个人预测上屏，输入后原编辑框仍持有键盘焦点，选区两端均为 6。

Windows 搜索框经进程令牌核实运行在 AppContainer 中，且实际加载了本次 DLL。通过真实搜索框核对了句末提交、全选替换和开头插入。这里未展示个人候选，普通用户个人库的快照和事件日志合计均保持 1,184,886 字节。受限宿主中的这些输入没有进入该库，无法据此建立个人学习样本。首次尝试中测试副本未经过设置程序的数据文件授权流程，搜索框只收到英文字母。运行设置程序、重新启动沙盒的 SearchHost 并等到选区生效后，基础输入和上述编辑用例均通过。

## Windows 宿主对照

Edge 与经典记事本均通过 `w → 空格` 上屏“明天去”，随后展示个人模型候选“图书馆”，再次空格得到“明天去图书馆”。
事件中个人候选具有独立来源、请求身份和实际模型版本，提交为 Confirmed。Edge 撤销后正文恢复“明天去”且候选消失。
敏感字段的 `w` / Escape 探针未产生采集事件；普通形码候选仍可能由基础输入路径显示，这不等于开启个人采集或个人预测。

经典记事本在开头插入“实验室”时，事件保留右文“明天去图书馆”；全选替换时保留选区“实验室明天去图书馆”，
最后只提交“图书馆”。其系统字体缺少中文显示字形，界面为方框，但候选、UTF-16 位置及采集文本一致。
验收环境原本未安装记事本，本次复用本机既有二进制及 MUI，没有联网下载。

不能据此宣称完整捕获所有宿主操作：Edge 本轮撤销没有产生可与预测提交关联的编辑事件。
不可观察通知不能被当作已证明的负反馈；受限/AppContainer 宿主、其它浏览器和完整连续更新/回退交互矩阵保留验收。
现有实现只在可靠观察到回退至提交前左右文时关联删除；其它外部操作使用 Unknown。
