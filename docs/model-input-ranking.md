# MI-09 排序快照进展

`core_engine::assistance::ranking::RankingRound` 为当前合法候选提供三种显示策略：
基础模式不请求推理；先基础后辅助可固定首位；等待辅助模式在截止前隐藏候选，
但选择操作始终有对应的基础身份。错误、低置信或超时回退，旧结果不能再改变该轮。
每轮最多 64 个候选；扩展分页必须由平台对同一候选集合构造视图。

分数只在当前模型内排序，minimum/margin 必须独立校准，不把原始分数当成概率。
固定首位只排序剩余项，不提高首选命中率。稳定排序保持同分项原来的位置。
翻页、定位、触摸按下必须先 freeze；点击需传捕获的 key/order stamp。
显示改序后旧位置点击会被拒绝，选择返回 CandidateId，不能直接按旧数组下标提交。

单元测试覆盖三模式、固定首位、等待中选择、失败/超时冻结、低置信、旧点击、
编辑器版本变化和非法分数。它尚未接入现有 SemanticEngine、Windows GDI、Android
候选栏或快捷键/自动上屏路径；平台必须统一使用该快照的身份进行提交。
MI-09 的真实输入行为与模式配置验收保持未完成。
