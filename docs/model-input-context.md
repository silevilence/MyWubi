# MI-06 共享上下文边界

`core_engine::assistance::context` 只保存受字符数限制的已确认前文，不持久化，也不实现
Debug/Serialize。编辑器及 epoch 改变、敏感输入或禁用时清空；外部编辑必须显式失效。
宿主可读取时提供权威前文；不能读取时只保留本会话已经确认成功的提交。
已知写入前拒绝不追加，部分写入或结果未知立即清空，不猜测正文。

UTF-16 边界解码可丢弃截断窗口开头的低代理项，其余非法代理组合拒绝读取。
中文、emoji、错误确认、替换、切框和敏感输入的共享层测试通过。

这里尚未接入 Windows TSF 读锁与编辑通知，也未接入 Android InputConnection，
不能据此宣称真实宿主前文一致。MI-06/07 的平台采集和设备验收保持未完成。
调用方必须先通过现有 Session 接受当前编辑确认，才能调用 acknowledged；
该缓冲区不代替 Session 的版本检查，不应从未确认的候选或待提交编码构造前文。
