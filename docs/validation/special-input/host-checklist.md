## 准备与顺序

1. 核对 [当前制品清单](2026-11-13/artifacts.json) 的哈希，复用本地 Setup/Portable/APK、三份普通码表、六份 `.mwe` 和许可。不得重新下载相同资源。明确记录安装方式、版本、宿主、DPI/字体、设备 ABI/API、屏幕尺寸和主题。
2. 保存当前设置及自定义资源，建立可恢复的测试配置；使用测试宿主和合成文字。Windows 安装或切换 TIP 应限定到验收环境；Android 覆盖安装保留数据，不先卸载清数据。不得把实际工作文档用作输入测试。
3. 先完成设置/导入/备份流程，再完成宿主输入和生命周期，最后集中切换主题、DPI/大字体及可访问性。复用同一环境和已准备资源；只有验收项要求时重启、重建服务或换环境。
4. 结束后恢复原配置、原输入法状态并关闭本轮测试应用，随后在命令行整理证据。未执行或失败的行保持待验，记录具体缺口。

## 显示、可访问性与性能

- Windows：宽/窄设置窗口、键盘 Tab/Enter、明暗主题、100%/150%/200% DPI、大字体；长符号/组合字符的测量、绘制和点击区域一致，无字形时可读回退。真实按键到候选呈现 p95 ≤100 ms、p99 ≤150 ms。
- Android：手机/宽屏、横竖屏、系统大字体、明暗主题；软键盘不遮挡保存/错误提示，触摸目标至少遵循既有控件尺寸；TalkBack 名称、选中/禁用状态和错误可读，“日期时间”不误读成编码提示。真实触摸到候选呈现 p95 ≤200 ms、p99 ≤300 ms。
- Android JNI/PSS：按 SI-01 相同四组压力数据、预热/轮数，三轮分别保留；关闭 p95/p99 ≤25/50 ms，1024 未命中 ≤35/60 ms，多类别/32 规则 ≤150/250 ms，全集构建 ≤3 s，完整应用 PSS ≤256 MiB。API 34 x86_64 与 ARM64 真机分别记录，互不替代。
