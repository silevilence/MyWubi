# Unicode 分类与双端操作审查（2026-11-16）

审查基线为 `d147144`（此前全部浏览功能已先提交）。本次新增内容独立于该提交。

## 结论与修改

| 检查项 | 基线问题 | 本次处理 |
| --- | --- | --- |
| α、①、ā | α 在数学库、① 在其他符号库；ā 未单独收录 | 保留旧入口，新增希腊、圈号、拼音与拉丁分类 |
| Unicode 覆盖 | 首批数学 124、标点 49、其他符号 109 项，遗漏多个符号区块 | 增加 14 类，总计 20 类；17 个 Unicode 字符库共 15,979 项，逐码点检查 P*/S*/N* 无遗漏 |
| Android 入口 | 横排分类随数量增长，后部类别难发现；工具栏菜单过长 | 两处统一使用有高度上限的双列滚动选择器；保留 48dp 最小点击高度及不可用说明 |
| Windows 入口 | 六个标签直接铺开，扩展后超宽 | 单一分类入口，四列五行；查询面板可直接 F3 进入 |
| Windows 设置 | 资源目录和查询草稿各有固定六项数组，新增类别会越界 | 数量绑定共享分类清单；保留搜索、滚动和宽窄屏列表／详情结构 |
| 主码表切换 | 特殊资源与普通编码码表是不同模型 | 20 类进入特殊输入列表，不混入主码表选择器 |
| Windows 键盘 | 可选格子、翻页，但不能纯键盘打开全部及切换分类／查询输入方式 | F2 全部／搜索、F3 分类、F4 清空、F5 查询输入方式；分类方向键确认与 Esc 返回；辅助菜单每页 8 项 |
| 升级与备份 | 覆盖默认文件可能丢失用户维护内容，旧备份只有六类 | 保留旧文件，提供三个 Unicode 18 扩展副本；恢复旧备份保留新增类别配置；新备份携带 20 类 |
| 组合附加符与缺字 | 单独显示附标难辨认，部分系统字体无新码点字形 | 仅显示时加虚线圆，提交原始附标；缺字提示与码点标识保留 |

分类数量与逐类差额详见 [资源清单](../../../expressions/SPECIAL-TABLES.md)；完整机器可读审计见 [unicode-coverage.json](../../../expressions/unicode-coverage.json)。

## 范围

“符号/标点”按 Unicode General_Category 的 S* / P* 核对，排除 Default_Ignorable，并核对全部 N* 数字（含全角与各文字体系十进制形式）；另扩展拉丁、希腊、西里尔、音标、圈号、数字形式和部分组合附标。α、ā 在标准中属于字母，① 属于数字，不能只扫描 Symbol 类。

不包含所有文字体系、所有组合序列或隐形控制字符。其余文字码表需求与 Emoji 序列版本边界见资源清单。旧库差额按可独立选择的完整词条计算，不能解释为这些字符原本无法由普通键盘或其他输入方式获得。

来源：[Unicode 18.0.0](https://www.unicode.org/versions/Unicode18.0.0/)、[UCD 字段与分类规范](https://www.unicode.org/reports/tr44/)。四份 UCD 原文件固定版本和 SHA-256；首次取得后生成和验收全部离线复用。未下载字体、SDK、安装包或模型。

## 集中验收清单

1. 离线生成一致性、UCD 逐码点覆盖、代表别名、无损往返、配置独立性、旧备份兼容与升级不覆盖用户文件。
2. Windows 会话：全部 20 类完整分页、连续上屏、过期点击、F2～F5、分类取消、辅助菜单末页、失焦退出。
3. Windows 原生渲染：20 类和分类面板，浅深色，100%／150%／200% 缩放，网格和点击区域边界。
4. Android UIAutomator：横竖屏、正常／双倍字体，分类滚动到最后一类、候选点击、设置末类检索和旋转后草稿保留。
5. 最后统一运行 Windows Sandbox：复用本地 DLL 和码表，网络关闭；WPF UIA + 原生 MSAA 断言，合成按键走真实 TSF 输入。纯键盘覆盖辅助菜单第三页、20 类、α①ā 查询、清空、模式切换、分页、分类返回及退出；另回归鼠标、选区替换、失焦和停用分类。结束后关闭测试宿主和 Sandbox。
