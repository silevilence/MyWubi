# 生成式预测的多解人工判定方法

评测输入、模型和准入策略先冻结；审阅结果不回流调整本次保留集参数。单一参考答案的精确命中仅表示参考匹配，不表示其他续接一定错误。

每个盲审条目只显示随机化标识、已确认前文和待评价候选或完整选择链，不显示方法、模型、参考答案、概率与耗时。对应表独立保存在 `.key.json`，在审阅结束前不交给审阅者。空输出和零步链同样保留。

两名中文使用者独立评价，分歧由第三人裁决；候选标为合理、勉强、不合理、应停止或无法判断。合理要求语法衔接自然、语义不矛盾且不凭空引入前文不支持的专名或事实。专门领域词由具备该领域知识的人复核，知识不足标无法判断。续接不必等于参考答案；“北京→市”可以合理，但并非所有前文都适合继续输出。

连续链按最终全文与各步评价，记录首次不合理步骤；后一步与前一步矛盾（例如“天气晴朗多云”）、回环、重复、角色漂移、句末继续以及不合语境的领域跳跃均记录。零步链标停止，并结合原始前文判断停止是否恰当，不从分母排除。误展示只在预先标定的停止负例上计算，不把所有未命中参考的候选都称误展示。

汇总每类票数、原始一致率、裁决结果、无法判断比例；保留原始独立票。没有独立审阅者实际投票时，审阅表保持空白，禁止填入代理意见冒充人工票。代理可以另写明确标注的定性问题分析，但不得据此报告人工准确率或宣称质量提升。
