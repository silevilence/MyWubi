# AK-17 键盘回归 · 2026-11-26

PGZ110（Android 15，ARM64）用 26、14、9 键输入「你好」「龘」「恭恭敬敬」「中华人民共和国」和用户词「联调用词」。每条轨迹混用键中心和左右偏移触点，逐键检查预编辑，最后点选并从独立应用读回正文。表内通过率只描述固定轨迹。

### 检索和 JNI

Windows Release 复用本地五笔 86 和拼音码表，三轮各测 1000 次。五笔分组检索 P95 为 89.1、69.5、63.6 μs，门槛为 10 ms，三轮均无预算截断。旧路径的五笔 P95 最大 6.0 μs，拼音最大 134.5 μs，相对冻结基线的增量均小于 0.2 ms。[三轮数据](core.json) · [旧路径基线](../../keyboards/lookup-baseline.json)

PGZ110 每轮用同一安装包、同一词集分别测精确和分组输入，各 500 次。形码分组的 P95 增量为 +0.275、+0.227、+0.151 ms，拼音为 −0.104、+0.274、−0.594 ms，均低于 2 ms 门槛。保存了加入首键缓存前的三轮对照。[JNI 明细](jni.json)

首键缓存最多占用八个槽，每槽至多保留 1 MiB 的候选行及附加编码索引。用两套真实分组键盘依次查询后，五笔保留七组、62,591 行，索引数组占 4,026,656 字节。拼音保留七组、44,125 行，占 2,301,088 字节。数据未计槽头和引用计数开销。可通过 `cargo test --offline -p core_engine --lib real_layout_first_keys_keep_index_storage_within_budget -- --nocapture` 复核。

### Windows 实际上屏

最终 DLL 在 Windows Sandbox 的独立 WPF 编辑框中通过 52 项 UIA／MSAA 断言，核对普通形码、删除、翻页后选中同文候选并替换选区、表情浏览及宿主焦点。工作区 82 个测试程序通过 630 项，8 项条件测试忽略，含真实键盘缓存的资源测试。全部制品及资源来自本地。[DLL 摘要、编辑框状态和逐条结果](windows.json)

### 真机长测

15 条固定轨迹全部通过。安装包在外部编辑框保持焦点，先预热 50 次，然后用真实菜单在三套布局间切换 1000 次，持续 30 分钟。每 25 次核对焦点和正文，并采样输入法进程 PSS。预热结束为 192.6 MiB，最终为 198.3 MiB，增加 5.7 MiB，低于 10 MiB 门槛。四段各 250 次的均值分别为 193.79、194.81、195.94、197.29 MiB。四段均值逐段上升，单看这条曲线无法确认长期占用已趋稳。[完整曲线](keyboard-switch-pss.jsonl) · [逐词上屏结果](layout-comparison.jsonl)

### 手势、受限编辑框和可访问性

两类皮肤、独立八向及合并方向、三种按键布局、明暗主题、横竖屏共 48 组。每组的八次触摸都从真实编辑框回读了预期正文，共 384 次。另有 8 项手势专项通过。首次横屏测试点击了被键盘遮住的编辑框中心，产生多余字母；改为从编辑框可见上沿取得焦点，并在手势开始前检查空正文，24 组横屏全部复测通过。[48 组触摸及上屏](gesture-matrix.jsonl)

ColorOS 密码框实际交给系统安全键盘，MyWubi 字母键不可见。API 34 AOSP 模拟器允许第三方输入法处理该字段，同一套模板测试通过，宿主回读了输入字符。在 PGZ110 保留系统安全键盘设置。实际 TalkBack 语音按既有决定免测，静默可访问性操作名已随手势矩阵核验。[系统当前输入法与窗口](password-owner.json) · [模拟器结果](../si17/emulator.json)
