# SI-15 特殊输入回归 · 2026-11-26

PGZ110（Android 15，API 35，ARM64）通过隔离安装包加载本地五笔码表、20 类特殊输入资源与 1024 条规则。输入法在独立宿主编辑框中保持可见。更新运行中的资源时，三轮整进程峰值分别为 **228.3、228.6、238.6 MiB**，门槛为 256 MiB。三轮构建均在 1.34 秒内完成，门槛为 3 秒。[真机原始数据](si-device-benchmark.jsonl)

保留全部词条、搜索别名、同文候选和反查编码。共享索引改为连续存储，加载器及时释放中间数据。Android 设置在资源开关旁提示同时启用多个大库可能增加内存及重新加载耗时。

下表取三轮各自 P95、P99 的最大值。每轮预热 20 次，五字符路径测 1000 次，另两组各测 200 次。Windows 核心的峰值工作集为 115.3 MiB，限值为 128 MiB。全集最长构建 868 ms，限值为 2 秒。[核心采样和制品摘要](core-memory.json) · [冻结门槛](../../../special-input-design.md)

| 场景 | Windows 核心 P95 / P99 | 核心门槛 | Android JNI P95 / P99 | JNI 门槛 |
|---|---:|---:|---:|---:|
| 全关 | 3.700 / 10.200 μs | 10 / 20 μs | 1.654 / 7.878 ms | 25 / 50 ms |
| 1024 条未命中 | 23.800 / 39.300 μs | 100 / 200 μs | 1.138 / 6.382 ms | 35 / 60 ms |
| 多类别命中 | 2.713 / 3.660 ms | 10 / 20 ms | 12.810 / 15.344 ms | 150 / 250 ms |
| 同码 32 条 | 0.035 / 0.046 ms | 10 / 20 ms | 3.459 / 9.623 ms | 150 / 250 ms |

同一测试 APK 中的 ARM64 库在 Android ART 上通过 1168 次协议及控制请求，覆盖 SI-C01～SI-C11。设备另运行 19 项 ARM64 核心测试，从共享协议入口注入固定时钟，检查跨日、拒绝写入、重试、过期 ID 和时钟读取次数。两种执行方式分别记录。[ART 断言与库摘要](art-cases.json) · [设备固定时钟测试](arm-clock-tests.txt)
