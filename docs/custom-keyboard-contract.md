# Android 自定义键盘契约与基线（AK-01）

固定日期：2026-11-14。外观只改变绘制；布局定义矩形命中区域和语义动作；映射定义一个编码位置的字符集合。三者有独立身份和版本，可独立组合或同 ZIP 分发。导入和换肤均不激活布局，只有用户明确选择并应用才改变输入。

## 范围与动作

首版覆盖 26、14、9 键、分体、错列及不同宽高矩形；不接受重叠、多边形、放射状命中区域。十四键配对来自映射配置，不是双拼。标签仅用于显示，不产生输入。密码使用内置确定字符键盘，数字/电话输入数字，英文/网址使用可精确输入的布局。

普通键状态为按下 → 点击、长按或滑动之一 → 松手派发一次。八方向按顺时针顺序为上、右上、右、右下、下、左下、左、左上；正中方向左右各 22.5°，边界归顺时针一侧。距离使用 dp，进入滑动阈值 24 dp，中心取消半径 12 dp，方向迟滞 5°。长按沿用 500 ms；进入滑动后回中心取消，松手不补点击。未绑定方向、同键第二触点、系统取消、失焦、旋转、销毁和组合 revision 变化均取消，停止计时。按下视觉不改变命中区域。不同按键保留双拇指独立点击，同键第二触点取消该键。

退格使用独立状态机：短按松手删除一次，长按连续删除；上滑待清空停止重复，松手清空一次；下滑撤销待清空可恢复重复，已删除内容不恢复；系统取消既不点击也不清空。不可叠加通用方向动作。所有方向提供命名可访问操作。

## 输入状态和固定轨迹

确定字符 `a` 与字符组 `{a,b}` 是不同输入事件；组占一个位置，不能提交字符串 `ab`，不能转成万能键。原始组仍歧义，即使剪枝仅有一个候选，也不能宣称已明确字母。显式消歧某位置后可撤回；退格优先撤回消歧，随后删除一个位置。Enter 对未确定序列仅提示先消歧，内部标记永不写入宿主。

| 轨迹 | 必须保持的结果 |
|---|---|
| 旧 26 键逐字、空格/数字选词、翻页、退格、回车、Esc | 对照现有 Session 的候选身份、正文、预编辑和 consumed |
| 点击 `{j,k}` → `j` → `a` → `d` | 保留四位置原始序列；不自动选择 j；不取日期时间 |
| 显式将首位确定为 j | 完整 jjad 才查询 SI，取时一次；翻页不重新取时 |
| 歧义组兼容有效 SI 编码或真前缀 | 禁止唯一自动提交及满码顶字，最多 32 个位置；仍可显式选普通词 |
| SI 停用或前缀走错 | 退出 SI 保护；无 SI 时普通组输入规则不变 |
| 纯换肤、映射切换、旧候选点击 | 换肤保留会话；不兼容切换等待会话结束；拒绝旧查询 |
| 宿主拒绝/未知写入结果 | 使用既有 prepare/ack 恢复语义，不重复写入 |
| 八向/宽上滑/长按竞争/回中心/未绑定/双触点 | 至多一个动作；取消后零动作 |

## 可复现测量与门槛

复用仓库真实 `tables/wubi86.dict` 和 `tables/pinyin.dict`。命令 `cargo run -p core_engine --example keyboard_baseline --release --locked --offline`，各表抽取 100 个实际编码，预热 200 次，测量 1000 次；候选上限 50，验证精确候选不丢失。记录文件字节数、CRC32、词条数、加载时间及 p50/p95/p99。该数据仅是主机纯检索时间，不是 JNI、触摸或屏幕延迟。

组检索门槛：小表与穷举参考集逐项一致，真实表查询完整或明确预算不足，不将截断结果当唯一；每次最多访问 100,000 个索引节点/词条，最多返回 10,000 个候选，独立索引预算 64 MiB。常用组序列主机 release p95 ≤10 ms；单字符旧路径相同条件 p95 不增加超过 20% 或 0.2 ms（取较宽者）。没有足够样本时重测而不据单次极值下结论。

已有 Android API34 x86_64 基线见 `android-benchmark-emulator.json`：主表 123,517 条，prepare/ack p95 3008 µs，展开 p95 8491.7 µs；旧版结果只作历史参考，不能当当前构建实测。当前设备重新基准须同 APK/宿主/输入序列比较；JNI p95 增量 ≤2 ms，输入到首次可见候选 p95 ≤50 ms。长测 30 分钟、1000 次切换后资源不得持续线性增长，预热后 PSS 增幅目标 ≤10 MiB；记录曲线和索引保留量。

## 集中验收准备

本次主机 release 结果见 `validation/keyboards/lookup-baseline.json`：五笔 136,239 条、拼音 65,125 条，两表各 1000 次精确候选存在性检查均通过；纯检索 p95 分别为 2.1 µs、53.4 µs。资源基线记录表文件大小及加载耗时；PSS 和实际可见延迟仍待设备采集，不用历史版本或主机检索时间填充。

本机已有 SDK/NDK、JDK、Gradle/Cargo 缓存和 Pixel 5 API34 AVD；初始 adb 无在线设备。先完成构建、定向测试与全量回归，再一次集中验证 26/14/9 键、形码/拼音/英文/密码、320/393/720 dp、横竖屏、1/1.3/2 字体、候选点击/展开和生命周期。Windows 对最终 DLL 做真实 TSF 回归。Android ARM64 物理真机、TalkBack、真实屏幕延迟和误触/耗时对照必须独立记录，模拟器或桌面示意图不能替代，缺设备则 AK-17 保持未完成。
