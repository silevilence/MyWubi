# 本地检索关系与边界

版本：1，2026-11-09。实际规则位于 `core_engine/src/expression_search.rs` 的 `RELATIONS`、`RESTRICTIONS`；修改规则需同步固定用例。仅供专用模式查找，不写回词条输出，不扩大普通输入的完整触发词匹配。

数据基础是本目录固定 Unicode 18.0 / CLDR 49 中文名称、标签及两个 MIT 颜文字来源的中文映射。具体来源、版本、摘要及许可见 `sources.json`、`kaomoji-sources.json`、`KAOMOJI-SOURCES.md`。检索关系由 MyWubi 针对本任务整理，按 `licenses/MyWubi-MIT.txt` 授权，没有抓取第三方词典或将站点释义编入数据。

| 内部概念 | 关联词 | 依据与限制 |
| --- | --- | --- |
| 禁止 | 不准、不许、严禁、禁行、不允许 | 用户指定查询及禁止类标志的中文表达；条件不得被删除 |
| 自行车 | 单车、脚踏车、骑车、骑行 | CLDR 自行车标签及用户“禁止骑行”样例；骑行到自行车是检索关联，不是通用语言等价 |
| 开心 | 高兴、快乐、喜悦、喜极而泣、笑颜逐开、微笑、大笑、哈哈、呵呵、笑 | 固定 CLDR 笑脸/猫脸标签及颜文字情绪类别；可召回同情绪类别，不宣称判断情境 |
| 难过 | 悲伤、伤心、不开心、不高兴、不快乐、哭泣、哭、悲痛 | 负面情绪保留为独立概念，最长短语先处理，不能把“不开心”拆成“开心” |
| 生气 | 愤怒、恼火 | 颜文字情绪类别的人工关联 |
| 惊讶 | 吃惊、震惊 | 颜文字情绪类别的人工关联 |
| 猫 | 猫咪、猫脸、喵 | 固定动物/猫脸标签及中文映射 |
| 狗 | 狗狗、犬 | 固定动物标签及中文映射 |
| 车 | 车辆、交通工具 | 宽泛类别；自行车名称含“车”，可满足该条件；不将任意交通工具认定为自行车 |

检索先合并选词边界并保留原分词供界面解释，以合并后的文本进行统一拆词；分次选“禁止”“车”和一次选“禁止车”产生同样结果。检索副本忽略空白与显式加号分隔、统一大小写；这些变换从不作用于提交字符串。优先保留上述概念，再用词库名称/别名/触发词/标签词汇拆解，完整名称不能遮蔽可拆解的多条件。未知连续文字作为条件保留，不丢弃或逐字泛化。

排序固定为完整名称/别名精确匹配 → 名称包含或全部条件匹配 → 名称/别名字符有序但不连续的宽松匹配。同级按词库稳定顺序；有上述完整结果时不混入部分结果，全部条件均未满足时才单独返回标有“部分匹配”的备选，先按满足条件数、再按词库顺序。无任何相关条件则空结果。保留不同肤色、性别、组合序列，结果不永久截断。

“禁止”“不是”“没有”“不要”“勿”“不”“无”“非”保留为限制条件；紧邻的否定前缀不能被正面子串匹配跨过。“禁止车”不会把普通自行车算作全部匹配，“猫不开心”不会按开心猫召回。规则不能分析任意否定范围、反话、复杂句法或任意自然语言；例如未列出的近义词可能无结果或只有部分匹配。全程本地执行，无模型或网络请求。
